# 성진산업 홈페이지

https://sungjinkorea.com

- `products-data.js` – **제품 목록** (제품 추가·수정은 이 파일만 고치면 제품소개 페이지에 자동 반영)
- `products.html` – 제품소개 페이지
- `product-offset-flange.html` – 직편심 플랜지 상세 (3D 뷰어, 모델은 `js/offset-flange-3d.js`)
- `product-concentric-flange.html` – 정심 플랜지 상세 (같은 3D 모델을 `offset: 0` 으로 사용)
- `images/` – 제품 이미지
- `index.html` – 첫 페이지 내용 (`<!-- 수정: ... -->` 표시된 곳을 실제 내용으로 바꾸세요)
- `styles.css` – 디자인
- `script.js` – 모바일 메뉴 등 동작
- `CNAME` – 연결된 도메인

임시 사진은 Unsplash(무료 라이선스) 이미지를 링크로 사용 중입니다. 실제 제품 사진이 준비되면 교체하세요.

GitHub Pages로 호스팅되며, `main` 브랜치에 올리면 1~2분 뒤 사이트에 반영됩니다.
